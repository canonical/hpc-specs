# Ubuntu High-Performance Computing Specification Documents

This repository hosts the development specifications for [Charmed HPC](https://github.com/canonical/charmed-hpc-docs). Each specification is a self-contained Markdown document that proposes, defines, or documents a design decision for the Charmed HPC ecosystem.

## Specifications

Each spec lives in its own folder under [`specs/`](specs/), named by its `UHPCNNN` index. Browse that directory for the full list.

> **Note:** This repository records *what was decided*, not *what has been built*. To check whether a spec has been implemented, consult the relevant charm repository (e.g. `slurm-charms`, `charmed-hpc-libs`).

To ask a question or start a discussion about a particular specification, please [open an issue](https://github.com/canonical/hpc-specs/issues/new?title=ISSUE+TITLE&body=*Please+describe+your+issue*).
